# How to fill site-content (adityacan.com)

This folder is the single source the website is built from. The full guide is in `START-HERE.md`.

1. Open a project folder, e.g. `01-strategy-content/satik-kura/`.
2. Fill the fields at the top of `project.md` (title, roles, years, links, permission) and the short sections below.
3. Drop images into its subfolders. File names starting with numbers set the order, and the rest of the name becomes the caption.
4. Big videos: upload to Vimeo or YouTube (unlisted is fine) and add the link to `links.md`. Don't put large video files here.
5. `permission:` must be `yes` for a project to appear on the live site. Use `ask` or `pending` while you check.
6. New project? Copy any project folder, rename it, edit `project.md`.
7. Unsure where something goes? Leave it in `_UNSORTED.md` and tell Claude.

Never put private documents here (contracts, pay documents, bank letters, cover letters, IDs).
